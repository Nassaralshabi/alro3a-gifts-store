# متجر مطبعة الروعة — نسخة HTML خالصة (ثيم أبيض/رمادي)

متجر إلكتروني كامل مبني بلغة **HTML + CSS + JavaScript خالصة** (بدون خادم أو إطار عمل)، مع ربط **كل صور الكتالوج الـ262** محلياً في مجلد `media/`.

## التشغيل الفوري

افتح `index.html` مباشرة في أي متصفح — لا يحتاج تثبيت أو خادم.

أو للنشر: ارفع محتويات هذا الفرع كما هي إلى أي استضافة ثابتة (GitHub Pages / Netlify / Vercel / أي مضيف ملفات) واجعل `index.html` هو صفحة البداية.

## المزايا

- **ثيم أبيض/رمادي فاخر**: خلفيات بيضاء بتدرجات رمادية فاتحة، أزرار فحمية أنيقة، ولمسات ذهبية (#f2bd66) للتمييز — بلا أي أخضر.
- **ثنائي اللغة**: عربي (RTL) / إنجليزي (LTR) بتبديل فوري، والاختيار يُحفظ.
- **262 منتجاً بصورهم الحقيقية** في 8 أقسام + بانرات رئيسية وشعار المتجر.
- **صفحة رئيسية جذابة**: سلايدر بنصوص حية فوق الصور، شريط مزايا متحرك، أيقونات رمادية متدرجة، ظهور تدريجي عند التمرير، لمعة على البطاقات.
- **متجر**: فلترة أقسام بصور مصغرة، بحث فوري، ترتيب بالسعر/الاسم، تحميل تدريجي.
- **صفحة منتج**: كمية، سعر (أو «حسب الطلب»)، منتجات مشابهة، استفسار واتساب.
- **سلة طلب** كاملة: كميات، إجماليات، حفظ الطلب في لوحة الإدارة وفتح واتساب برسالة جاهزة.
- **لوحة إدارة** `#/admin` (الرمز الافتراضي `1234`): إحصائيات، تعديل أسعار/تمييز/إتاحة المنتجات، إدارة الطلبات، إعدادات التواصل.
- **SEO جاهز**: Open Graph + Twitter Card + JSON-LD (Schema.org Store) + favicon وapple-touch-icon.
- **أزرار عائمة**: واتساب بنبض متحرك + زر العودة للأعلى.
- **متجاوب بالكامل** للجوال والتابلت وسطح المكتب، مع احترام `prefers-reduced-motion`.

## تخصيصات سريعة

- **الألوان**: متغيرات `:root` أعلى `index.html` (`--charcoal`, `--gold`, `--bg-tint`...).
- **المنتجات/الأقسام**: مصفوفة `DATA.products` / `DATA.categories` داخل الملف.
- **نصوص الواجهة**: قاموس `I18N` (عربي/إنجليزي لكل نص).
- **رقم واتساب والإعدادات**: من لوحة الإدارة ← الإعدادات (تُحفظ في localStorage)، أو `DATA.contact`.

> ملاحظة: بيانات السلة والطلبات والتعديلات تُحفظ محلياً في متصفح المستخدم (localStorage) — لا تُرسل لأي خادم. للحصول على إدارة مركزية متعددة الأجهزة، يلحق المتجر بخلفية حقيقية لاحقاً.
