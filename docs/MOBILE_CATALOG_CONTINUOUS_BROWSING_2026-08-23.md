# تصفح كتالوج الجوال المستمر

يحمّل كتالوج الجوال الآن **24 منتجاً لكل دفعة** بدلاً من 12، ثم يجلب الدفعة التالية تلقائياً عند الاقتراب من نهاية الصفحة. لا يوجد سقف لعدد الدفعات؛ يستمر التحميل وفق مؤشر الصفحة الخادمي حتى انتهاء الكتالوج. تُحمّل صور البطاقات بكسل وبفك ترميز غير متزامن كما كانت، وتبقى نافذة «عرض المزيد» بديلاً متاحاً عند الحاجة.

| التحقق | النتيجة |
|---|---|
| بيانات اختبار معزولة | تحمّل 73 منتجاً عبر صفحات متتابعة من دون تكرار. |
| كتالوج الموقع الفعلي على 375px | تحمّل 262 منتجاً حتى النهاية، واختفى مؤشر «عرض المزيد». |
| العرض | لم يظهر تمرير أفقي؛ بقي عرض المستند 375px. |
| سلامة المتصفح | لا أخطاء في وحدة التحكم أثناء التمرير. |

تُحفظ استجابة الكتالوج لمدة عشر دقائق وتبقى الصور تحت سياسة التحميل الكسول، لذلك لا يُرسل كامل الكتالوج أو جميع صوره في الاستجابة الأولى.
