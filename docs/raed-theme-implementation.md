# تطبيق لغة ثيم Raed على متجر الرؤى

تمت مراجعة ثيم Raed المرجعي لاستخلاص **الأنماط البنيوية** فقط دون نسخ شفرته أو محتواه: غلاف كامل العرض مع طبقة نص، روابط فئات دائرية، شبكة بنرات، قسم منتجات مميزة، ومزايا متجر واضحة.

| منطقة الواجهة | المواءمة في متجر الرؤى |
|---|---|
| الغلاف | عرض شرائح كامل بمحتوى عربي وإجراءات واضحة للمتجر والطلب المخصص |
| روابط الفئات | أيقونات دائرية قابلة للتمرير، مرتبطة بفئات الطباعة والهدايا الحالية |
| البنرات | شبكة بنرات لمناسبات الطباعة والبوكسات واللوحات باستخدام صور المتجر |
| المنتجات المميزة | منتج رئيسي كبير إلى جانب شبكة بطاقات منتجات |
| صفحات المتجر والمنتج | رأس كتالوج داكن، فلاتر كبسولية، نموذج طلب موحد، ومزايا تنفيذ وتوصيل |

> استخدم التطبيق لوحة ألوان تركوازية داكنة وذهبية وبيضاء لإبقاء الهوية مرتبطة بمطبعة الروعة، لا بهوية الثيم المرجعي أو محتواه.

تم التحقق من العرض عبر معاينات سطح المكتب والهاتف. تظهر معاينة المتصفح المعزولة أحيانًا قبل اكتمال استعلام الكتالوج؛ أما معاينة التطوير المرئية فتؤكد تحميل المحتوى والتخطيط في الصفحات المستهدفة.
