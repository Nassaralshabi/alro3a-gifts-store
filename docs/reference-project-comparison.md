# مقارنة المشروع المرجعي بمتجر الروعة

## حالة الوصول

يفتح رابط المشاركة صفحة إعادة تشغيل لمهمة بعنوان **«تصميم موقع ويب متكامل مع لوحة تحكم»**. عند الفحص الأولي، كانت المهمة مكتملة ولم تعرض الصفحة تفاصيل المشروع أو معاينة قابلة للتصفح؛ ظهر فقط خيار إعادة المشاهدة. لذلك لا يمكن بعد اعتماد أي تفاصيل واجهة أو وظيفة من الرابط من دون الوصول إلى محتوى إعادة التشغيل أو معاينة المشروع نفسها.

## منهج الاعتماد

سيقتصر الاعتماد على أنماط تجربة المستخدم، وتنظيم المحتوى، والوظائف التي تظهر فعلياً في المشروع المرجعي. لن تُنسخ العلامة التجارية أو النصوص أو الأصول المرئية الخاصة به؛ ستبقى هوية **Al Rawhaa** ومحتوى متجر الهدايا هي الأساس.
