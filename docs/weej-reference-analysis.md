# دراسة مرجعية لتجربة التصفح

تمت مراجعة الصفحة الرئيسية في [Weej](https://weej.sa/ar) والمتجر الحالي للرؤى. الفكرة المنقولة ليست الهوية البصرية أو المحتوى، بل تسلسل اكتشاف الكتالوج: الوصول السريع إلى التصنيفات، ثم أقسام منتجات مستقلة تحمل عنوانًا ورابط «عرض الكل»، ثم العروض والفوائد والتذييل.

| البعد | Weej | المتجر الحالي | اتجاه إعادة التصميم للرؤى |
| --- | --- | --- | --- |
| الوصول إلى التصنيفات | روابط تصنيفات أساسية مبكرة بعد البانرات | روابط علوية وفئات دائرية ضمن الصفحة | إبراز فئات الهدايا الحقيقية في شريط قابل للتمرير ومكوّن اكتشاف مختصر. |
| اكتشاف المنتجات | قسم منتج واضح يتبعه «عرض الكل» | قسم مختارات واحد في الصفحة الرئيسية | إنشاء أقسام منتجات متعددة مبنية على الفئات والمنتجات الفعلية. |
| التسلسل | بانرات ثم تصنيفات ثم كتالوج وفوائد وتذييل | سلايدر ثم مزايا وفئات وبطاقات ترويجية ومختارات | تقليل هيمنة السلايدر وإعطاء الكتالوج مساحة أوضح بعد التصنيفات. |
| الهوية | هوية مطبعة مستقلة | هوية الرؤى بألوان كحلية وتركواز ولمسات ذهبية | الإبقاء على هوية الرؤى وعدم نقل شعارات أو صور أو نصوص أو أساليب Weej. |

تؤكد هذه الدراسة أن التنفيذ سيستخدم بيانات المتجر الحالية، ولن ينشئ مراجعات أو تقييمات أو شهادات عملاء مصطنعة.

## أنماط واجهة قابلة للتطبيق

الفحص الممتد للصفحة المرجعية أكد وجود سلايدر ترويجي قصير، وفئات مرئية، ثم صفوف منتجات أفقية متتابعة حسب الفئة. يحمل كل صف عنوانًا ورابط «عرض الكل» وأزرار تنقّل، وتضم بطاقاته صورة واسمًا وتفاعل إضافة مباشر. ينتهي التسلسل بعرض اجتماعي وفوائد وتذييل ذي أعمدة منظمة.

| النمط | تطبيقه المقترح في الرؤى |
| --- | --- |
| صفوف كتالوج متتابعة | صفوف للمنتجات المميزة والفئات الواقعية ذات أكبر عدد من المنتجات، لا تصنيفات Weej. |
| رابط «عرض الكل» | رابط موحد إلى صفحة الكتالوج المفلترة بالفئة عند كل صف. |
| استكشاف أفقي | تمرير أفقي باللمس على الجوال، وشبكة أوسع مع تحكم واضح على سطح المكتب. |
| إثبات اجتماعي | لا يُضاف قسم مراجعات حتى تتوفر مراجعات حقيقية معتمدة؛ ستُستخدم بدلاً منه دعوة واضحة لتواصل الطلب والتخصيص. |
| تذييل هرمي | تقسيم معلومات الرؤى الفعلية إلى العلامة، تصفح المتجر، التواصل، والوصول والاستلام. |

## الفئات المتاحة للرؤى

سيُبنى ترتيب الأقسام على الفئات الفعلية ذات كثافة المنتجات الأعلى، بدلاً من إنشاء فئات للهدايا لا تدعمها البيانات الحالية.

| الفئة | عدد المنتجات المتاحة | الاستخدام المقترح في الصفحة الرئيسية |
| --- | ---: | --- |
| مطبوعات المناسبات | 106 | قسم اكتشاف رئيسي متقدم. |
| بوكسات وتغليف | 43 | قسم مميز مع دعوة لاستكشاف التغليف. |
| طباعة حسب الطلب | 37 | قسم مستقل يبرز قابلية التخصيص. |
| ستيكرات وليبلات | 31 | صف كتالوج أفقي. |
| أكياس ورقية | 18 | صف كتالوج أو رابط عرض الكل. |
| هدايا إعلانية | 17 | قسم مميز مرتبط بالطلبات الخاصة. |
| ستاندات ولوحات | 9 | قسم قصير بصور كبيرة. |
