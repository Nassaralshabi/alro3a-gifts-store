# بيان الأصول المضمّنة

تحتوي حزمة HTML على الصور التالية داخل مجلد `assets/`، ولا تعتمد هذه النسخة على روابط صور خارجية. كما يُبنى مجلد `assets/published/` من صور المنتجات المنشورة والمعالجة فعلياً في قاعدة البيانات وقت إنشاء الحزمة.

| الملف | الاستخدام |
|---|---|
| `logo.webp` | شعار مطبعة الروعة في الرأس. |
| `national-gift-set-1.jpeg` | الشريحة الأولى لأطقم اليوم الوطني الإماراتي. |
| `national-gift-set-2.webp` | الشريحة الثانية لأطقم اليوم الوطني الإماراتي. |
| `hero-graduation.jpg` | الشريحة الثالثة للسلايدر. |
| `packaging-gift-box.jpg` | صورة قسم الطلب المخصص. |
| `published/` (**262 ملفاً**) | صور المنتجات المنشورة والمعالجة والمعتمدة عند إنشاء الحزمة. |
| `published-assets-manifest.json` | سجل أسماء ومسارات أصول الكتالوج المضمّنة. |

لا يشمل البيان أصولاً مصدرية غير منشورة أو صوراً غير مستخدمة. ارفع المجلد كاملاً كما هو للمحافظة على المسارات النسبية للصور.
