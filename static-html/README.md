# نسخة HTML ثابتة لمطبعة الروعة

## النشر

ارفع **كل الملفات والمجلدات داخل الحزمة الناتجة** إلى جذر أي استضافة ثابتة، مثل Cloudflare Pages أو Netlify أو GitHub Pages أو cPanel. لا تحتاج هذه النسخة إلى Node.js أو قاعدة بيانات أو ملف `.env`.

للمعاينة محلياً، افتح `index.html` في المتصفح أو قدم المجلد من أي خادم ملفات بسيط.

## ما تعمل عليه النسخة

تتضمن الصفحة العامة، التصميم المتجاوب، شاشة تحميل مرتبطة بهوية الروعة، سلايدر تلقائي بسرعة 2.4 ثانية، وكتالوجاً محلياً من **262** منتجاً منشوراً وصورة معالجة داخل `assets/published/`. وتتضمن أيضاً روابط واتساب وواجهة `admin.html` لإدارة النصوص المحلية وعرض مكتبة الصور.

> راجع `FULL_STATIC_HTML_INSTALLATION.md` لخطوات الرفع، واستخدام لوحة التحكم المحلية، وتصدير نسخة JSON احتياطية من الإعدادات.

## ما لا يمكن أن يظل ثابتاً

لا تعدّل `admin.html` قاعدة البيانات ولا تؤمن دخولاً حقيقياً؛ تحفظ التغييرات في LocalStorage الخاص بالمتصفح ويمكن تصديرها يدوياً. لا ترفع رابط `admin.html` على موقع عام على أنه لوحة إدارة آمنة. الطلبات وتسجيل الدخول والحماية والبحث المتصل بالبيانات تحتاج خادم Node.js وtRPC وقاعدة بيانات. استخدم حزمة Node.js السابقة إن أردت هذه الميزات الحية كاملة.
