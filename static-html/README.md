# نسخة HTML ثابتة لمطبعة الروعة

## النشر

ارفع **كل الملفات والمجلدات داخل `static-html/`** إلى جذر أي استضافة ثابتة، مثل Cloudflare Pages أو Netlify أو GitHub Pages أو cPanel. لا تحتاج هذه النسخة إلى Node.js أو قاعدة بيانات أو ملف `.env`.

للمعاينة محلياً، افتح `index.html` في المتصفح أو قدم المجلد من أي خادم ملفات بسيط.

## ما تعمل عليه النسخة

تتضمن الصفحة العامة، التصميم المتجاوب، سلايدر تلقائي بسرعة 2.4 ثانية، روابط الفئات، وروابط واتساب، وأصول الصور المستضافة.

## ما لا يمكن أن يظل ثابتاً

الكتالوج المتصل بقاعدة البيانات، البحث الفوري، الطلبات، تسجيل الدخول ولوحة الإدارة ليست جزءاً من HTML الثابت لأنها تحتاج خادم Node.js وtRPC وقاعدة بيانات. استخدم حزمة Node.js السابقة إن أردت هذه الميزات كاملة.
