# حزمة مشروع مطبعة الروعة الكاملة

تتضمن هذه الحزمة نسخة المصدر، ونسخة محلية لجميع أصول الكتالوج والبانرات، وبيانات كتالوج عامة قابلة للاستيراد. **لا تتضمن** هذه الحزمة بيانات العملاء أو الطلبات أو كلمات المرور أو مفاتيح التشغيل.

| المسار | المحتوى |
|---|---|
| `app/` | مصدر تطبيق React + Express وملفات الإعداد والاختبارات والوثائق. |
| `assets/media/` | جميع صور المنتجات والبانرات التي تم تصديرها من الكتالوج. |
| `assets/asset-manifest.json` | خريطة تربط كل رابط صورة أصلي بالنسخة المحلية داخل الحزمة. |
| `data/catalog-content.json` | الفئات والمنتجات والمحتوى العام للصفحة؛ لا يحوي بيانات العملاء. |

## التشغيل

من داخل مجلد `app/` نفّذ `pnpm install` ثم وفّر متغيرات البيئة الخاصة بك، ومنها اتصال قاعدة البيانات ومفاتيح التخزين والمصادقة، وبعدها شغّل `pnpm dev`. لا تُدرج مفاتيح أو كلمات مرور حقيقية داخل المشروع أو الأرشيف.

## استخدام الصور محليًا

الصور موجودة داخل `assets/media/`، وملف `assets/asset-manifest.json` يوضح تطابقها مع روابط الكتالوج الأصلية. عند نقل المشروع إلى تخزين جديد، ارفع ملفات `assets/media/` إلى التخزين المطلوب ثم حدّث روابط الصور في البيانات وفق ملف المطابقة.

> الحزمة معدّة كنسخة مصدر وأصول كاملة قابلة للنقل. يعتمد تشغيل الموقع الفعلي على إعداد قاعدة بيانات وتخزين ومفاتيح مصادقة تخص بيئة الاستضافة الجديدة.
