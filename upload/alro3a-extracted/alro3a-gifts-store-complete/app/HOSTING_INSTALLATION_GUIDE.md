# دليل تثبيت واستضافة متجر الروعة

## ما الذي تتضمنه النسخة

تحتوي الحزمة على **ملفات الموقع المصدرية كاملة** وبناء الإنتاج الحالي في `dist/`: واجهة React، خادم Express وtRPC، مخطط قاعدة البيانات وملفات الاختبارات والبناء. لا تتضمن `node_modules` أو ملفات Git أو السجلات المحلية أو ملفات الأسرار. يجب أن تستضيفها على منصة تدعم **Node.js 22 أو أحدث** وقاعدة بيانات MySQL/TiDB متوافقة.

> هذا التطبيق ليس موقعاً ثابتاً فقط؛ فهو يحتاج خادم Node.js لتشغيل الكتالوج والطلبات ولوحة الإدارة وtRPC. لذلك لا يصلح نشره كملفات HTML فقط على استضافة ثابتة.

## المتطلبات

| المتطلب | سبب الحاجة |
|---|---|
| Node.js 22+ وCorepack | تشغيل الخادم وإدارة `pnpm`. |
| قاعدة MySQL أو TiDB | تخزين المنتجات والفئات والطلبات ومحتوى الصفحة والإدارة. |
| متغيرات البيئة | حماية الجلسات وربط قاعدة البيانات والتكاملات الاختيارية. |
| دومين مع HTTPS | موصى به للكوكيز وتدفق تسجيل الدخول. |

## التثبيت المحلي أو على خادم VPS

1. فك ضغط الملف ثم ادخل إلى مجلد المشروع.
2. فعّل مدير الحزم وثبّت الاعتماديات:

   ```bash
   corepack enable
   pnpm install --frozen-lockfile
   ```

3. أنشئ ملف الإعدادات محلياً، بالرجوع إلى `ENVIRONMENT_TEMPLATE.md`، ثم أضف القيم الحقيقية داخل الخادم فقط:

   ```bash
   touch .env
   ```

4. في أول قاعدة بيانات جديدة، شغّل ترحيلات Drizzle بعد ضبط `DATABASE_URL`:

   ```bash
   pnpm db:push
   ```

5. يمكنك تشغيل بناء الإنتاج المرفق مباشرة بعد تثبيت الاعتماديات، أو إعادة البناء إن غيرت إعدادات عامة تبدأ بـ `VITE_`:

   ```bash
   pnpm start
   ```

   ولإعادة البناء:

   ```bash
   pnpm build
   pnpm start
   ```

الخادم يستخدم قيمة `PORT` التي توفرها منصة الاستضافة، أو المنفذ `3000` عند عدم وجودها.

## إعدادات Render أو Railway أو VPS Node.js

استخدم الأوامر التالية في إعدادات الخدمة:

| الحقل | القيمة |
|---|---|
| Build command | `corepack enable && pnpm install --frozen-lockfile && pnpm build` |
| Start command | `pnpm start` |
| Runtime | Node.js 22+ |
| Health check | `/` |

أدخل القيم الواردة في `ENVIRONMENT_TEMPLATE.md` من لوحة الأسرار في منصة الاستضافة؛ لا ترفع ملف `.env` إلى Git أو إلى ملف ZIP أو إلى مساحة عامة.

## التكاملات المرتبطة ببيئة Manus

تستخدم النسخة الحالية OAuth وتخزيناً وسيطاً يمكن ربطهما بخدمات Manus. عند النقل إلى مزود خارجي، يلزم توفير بدائل صالحة أو مفاتيح بيئة مخصصة لـ OAuth وForge/S3. من دون ذلك قد تعمل صفحات الكتالوج العامة إذا كانت البيانات والصور متاحة، لكن تسجيل الدخول أو التخزين أو بعض التكاملات لن يعمل كاملاً.

## اختبار بعد النشر

تحقق من الصفحة الرئيسية، ثم من الكتالوج وصفحة منتج وإرسال طلب تجريبي. بعد ذلك تحقق من بوابة الإدارة بحساب مخصص. راقب سجل الخادم لأي قيمة بيئة ناقصة ولا تطبع قيم الأسرار في السجلات.

## محتويات ملف ZIP

تضم الحزمة مجلدات `client/` و`server/` و`drizzle/` و`shared/` و`storage/` و`scripts/` و`dist/`، إضافة إلى ملفات إعداد المشروع ودليل التثبيت و`ENVIRONMENT_TEMPLATE.md`. تُستبعد `node_modules/` و`.git/` و`.manus-logs/` والأصول المحلية الكبيرة؛ الصور المستخدمة حالياً تشير إلى روابط التخزين المنشورة في المتجر.
