# بيان حزمة الاستضافة

| العنصر | الحالة |
|---|---|
| نوع الحزمة | مصدر الموقع الكامل مع بناء إنتاج `dist/` |
| تشغيل التطبيق | `pnpm start` بعد تثبيت الاعتماديات وإعداد متغيرات البيئة |
| مدير الحزم | pnpm عبر Corepack |
| إصدار Node المقترح | 22 أو أحدث |
| قاعدة البيانات | MySQL أو TiDB عبر `DATABASE_URL` |
| الأسرار | غير مضمنة؛ راجع `ENVIRONMENT_TEMPLATE.md` |
| الملفات المستبعدة | `node_modules/` و`.git/` و`.env*` و`.manus-logs/` وملفات التطوير المحلية |

## التحقق قبل التغليف

تم تمرير اختبارات Vitest وفحص TypeScript وبناء الإنتاج في النسخة المنشورة الأخيرة. استخدم `pnpm build` على الاستضافة إذا تغيرت أي قيمة عامة تبدأ بـ `VITE_` أو عند تحديث المصدر.
