# لوحة HTML للإدارة الحية

## الغرض والمسار

تُخدّم الصفحة `client/public/admin-live.html` من **نطاق تطبيق المتجر نفسه** تحت `/admin-live.html`. وهي واجهة HTML خفيفة للإعدادات المتكررة، وليست بديلاً عن لوحة React الكاملة في `/admin`.

> لا تعمل الإدارة الحية من ملف ZIP الثابت أو عبر `file://`، لأن الحزمة الثابتة لا تحتوي خادم المصادقة أو قاعدة البيانات. تبقى `static-html/admin.html` لوحة LocalStorage محلية فقط.

## الحماية

| الطبقة | التطبيق |
|---|---|
| المصادقة | تستخدم الصفحة إجراء `auth.adminMe` وجلسة المدير الحالية، وتدعم تسجيل الدخول المحلي الموجود أو حساب المالك المرتبط عبر `/admin`. |
| الصلاحيات | لا تقرأ ولا تحفظ إعدادات الإدارة إلا عبر `adminProcedure`. يُرفض الطلب بلا جلسة مدير برمز `FORBIDDEN`. |
| نطاق البيانات | لا تقبل الواجهة إلا الهاتف وواتساب والعنوان وInstagram ومحتوى الشريحة الأولى. لا تسمح بمفاتيح محتوى عامة أو بيانات عملاء أو أوامر. |
| الجلسة والعميل | تستخدم الطلبات `credentials: same-origin`. لا تحفظ الصفحة كلمات مرور أو جلسات أو تعديلات في LocalStorage. |
| الفهرسة | الصفحة تحمل `noindex,nofollow` لتجنب فهرستها من محركات البحث. |

## البيانات التي تعدلها

يجري الحفظ عبر مفاتيح محتوى مقيدة: `contact_phone` و`contact_whatsapp` و`contact_address_ar` و`contact_instagram` و`home_hero_badge_ar_1` و`home_hero_title_ar_1` و`home_hero_subtitle_ar_1`. تعرض واجهة المتجر هذه القيم عبر إجراءات الكتالوج العامة التي ترجع محتوى مناسباً للعرض فقط.

## التحقق المحلي

نفّذ ما يلي والخادم قيد التشغيل:

```bash
pnpm test:e2e
pnpm test -- --run
pnpm check
```

اختبار `test:e2e` يفتح Chromium بسياق جديد ويعترض بيانات الكتالوج والإدارة ببيانات اختبار مضمّنة. لا ينشئ منتجات أو طلبات أو تعديلات في قاعدة البيانات الحية؛ ويحظر كل مسارات الكتابة، باستثناء محاكاة حفظ الإدارة الحية داخل الاعتراض نفسه للتحقق من الواجهة.
