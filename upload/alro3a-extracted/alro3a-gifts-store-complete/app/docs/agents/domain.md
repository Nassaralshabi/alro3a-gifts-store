# Domain Docs

يستخدم هذا المستودع ترتيب **سياق واحد**. قبل استكشاف مجال ذي صلة، اقرأ `CONTEXT.md` إن وجد، ثم قرارات `docs/adr/` المتصلة بالعمل. إن لم توجد هذه الملفات، تابع الاستكشاف من دون افتراضات أو إنشاء وثائق مجال فارغة.

تستخدم وثائق المجال مستقبلاً لتثبيت المصطلحات الخاصة بمتجر مطبعة الروعة، مثل المنتجات والفئات وطلبات التخصيص وسلة الطلب ولوحة الإدارة. لا تستبدل المصطلحات المحددة في `CONTEXT.md` بمرادفات متى وُجدت الوثيقة.
