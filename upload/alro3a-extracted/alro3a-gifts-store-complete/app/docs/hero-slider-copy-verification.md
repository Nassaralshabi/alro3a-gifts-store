# التحقق من نصوص السلايدر الرئيسية

تم ربط السلايدر الرئيسي بخمس مجموعات محتوى مستقلة. تحتوي كل مجموعة على شارة وعنوان ووصف قصير بالعربية والإنجليزية، وتظهر النصوص بحسب البانر النشط بدلاً من تكرار رسالة عامة واحدة.

| جانب التحقق | النتيجة |
| --- | --- |
| سطح المكتب | ظهر عنوان البانر الأول ووصفه فوق الصورة مع أزرار التنقل والدعوة إلى الإجراء. |
| الجوال | خُفّض حجم العنوان والوصف للشاشات الصغيرة وأضيف ظل نصي لتحسين وضوح المحتوى فوق الصور المطبوعة. |
| منطق المحتوى | يعيد مسار محتوى الصفحة الرئيسية خمس شرائح، ولكل شريحة حقول نصية مستقلة. |
| الاختبارات | نجحت اختبارات Vitest وفحص TypeScript بعد التعديل. |
