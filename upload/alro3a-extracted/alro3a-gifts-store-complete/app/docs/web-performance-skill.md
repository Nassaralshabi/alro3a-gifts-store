# مهارة تحسين أداء الويب

يعتمد المشروع مهارة `web-performance-weak-network` لمراجعة سرعة التحميل وسرعة التجاوب، مع أولوية للهواتف والاتصالات البطيئة أو غير المستقرة.

عند تعديل واجهة أو مسار يحمّل بيانات أو أصولًا جديدة، استخدم المهارة لتحديد خط أساس، وتحديث ميزانية الأداء، وتقليل تكلفة المسار الحرج، ثم التحقق من حالات التحميل والفشل وإمكانية الوصول. توجد المهارة القابلة للإضافة إلى بيئة Manus في `/home/ubuntu/skills/web-performance-weak-network/SKILL.md`، بينما يحتوي المرجع المرفق بها على قالب ميزانية الأداء ومصفوفة الاختبار وآلية مراجعة الحدود.

هذا التوثيق لا يعني أن كل مسارات المتجر قد خضعت لقياس ميداني؛ يجب تسجيل القياسات الفعلية قبل وبعد كل تحسين، وعدم اعتبار الحدود الأولية نتائج محققة.
