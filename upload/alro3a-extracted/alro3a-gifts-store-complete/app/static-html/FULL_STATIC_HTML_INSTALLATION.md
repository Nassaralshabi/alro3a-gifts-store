# دليل رفع الحزمة HTML الكاملة

## محتويات الحزمة

| المسار | الغرض |
|---|---|
| `index.html` | واجهة متجر الروعة الثابتة. |
| `admin.html` | لوحة محلية لتعديل الاسم وواتساب ونص الشريحة الأولى. |
| `assets/` | الشعار، صور السلايدر، و**262** صورة منتج منشورة ومعالجة. |
| `store-data.js` | بيانات كتالوج المنتجات التي تقرؤها الصفحتان محلياً. |
| `published-assets-manifest.json` | سجل أصول كتالوج المنتجات المضمّنة. |

## الرفع إلى استضافة ثابتة

1. فك ضغط الملف، ثم افتح المجلد `alro3a-gifts-static-html-full` الناتج.
2. ارفع **كل محتويات هذا المجلد** إلى جذر الاستضافة الثابتة؛ لا ترفع ملف ZIP نفسه أو المجلد الأب فقط.
3. اجعل `index.html` هو ملف البداية. يجب أن تبقى مجلدات `assets/` وملف `store-data.js` في مستواها الحالي.
4. افتح الصفحة الرئيسية، ثم افتح `admin.html` للتأكد من ظهور عدّادات الصور والمنتجات.

## استخدام لوحة التحكم المحلية

تعمل `admin.html` في المتصفح فقط. احفظ التعديلات، ثم استخدم زر **تصدير JSON** للاحتفاظ بنسخة احتياطية من إعدادات هذا المتصفح. لا تتزامن هذه التعديلات تلقائياً مع ملفات الموقع أو أجهزة أخرى أو قاعدة بيانات المتجر.

> لوحة HTML مفيدة للمعاينة المحلية وإعداد النصوص، لكنها **ليست** لوحة إدارة حية أو محمية. لا تستخدمها لإدارة الطلبات أو بيانات العملاء، ولا تعتمد عليها في بيئة تتطلب صلاحيات دخول أو مزامنة متعددة المستخدمين.

## لوحة الإدارة الحية الآمنة

تتوفر لوحة HTML حية منفصلة عند نشر تطبيق Node.js الكامل على نطاق المتجر نفسه عبر المسار `/admin-live.html`. تستخدم هذه اللوحة جلسة المدير المحمية للموقع، وتحدّث بيانات التواصل ومحتوى الشريحة الأولى في قاعدة البيانات مباشرة. لا تُضمَّن في حزمة الاستضافة الثابتة، لأن الحزمة لا تتضمن خادماً أو مصادقة أو قاعدة بيانات. راجع `docs/LIVE_HTML_ADMIN.md` في مصدر المشروع قبل استخدامها.

## النطاق الوظيفي

تحتوي الحزمة على التصميم والكتالوج والصور والسلايدر والتفاعل المحلي. لا تشمل هذه النسخة الثابتة تسجيل الدخول الآمن أو الطلبات أو التحديث الحي للمنتجات أو البحث المتصل بقاعدة البيانات. لهذه الوظائف، يلزم نشر حزمة Node.js مع قاعدة البيانات والمتغيرات السرية بشكل آمن.
